Organizar páginas

Separar em vários arquivos

Os números são os das páginas como estão agora na tela (depois de reordenar e tirar). Vários arquivos vêm juntos num .zip.

Número de página

O número entra no pé de cada página quando o PDF for gerado ("Gerar o PDF"), separado ou comprimido.

Comprimir (reduzir o tamanho)

O texto continua texto (dá para selecionar e pesquisar); o SAGA reduz as fotos e as páginas escaneadas que estão dentro do PDF. Se não diminuir, avisa e mantém o original.

Atenção: aqui cada página vira uma imagem.O texto deixa de ser selecionável e não dá mais para copiar ou pesquisar palavras no PDF. Se o resultado ficar maior, o SAGA mantém o original.

Editar a página

Escreva um texto ou tape uma área. As mudanças entram no PDF ao baixar.

PDF protegido por senha

A senha é usada só aqui, para abrir o arquivo, e não é guardada. Com senha, as páginas entram como imagem no PDF novo (o texto deixa de ser selecionável).
